## 🕹️ 이번 업데이트 핵심 사항

### 1. 20초 대결 시간 & 10초 결과 확인 후 자동 진행
- **가위바위보 결정 시간: 20초** (20초 동안 손이 빠르게 바뀌며 5초 이하 시 긴박 비프음 알림).
- **결과 화면 노출 시간: 10초** (10초 동안 나와 상대의 손, 파워, 영토 이동을 확인).
- **자동 연속 진행**: 10초가 지나면 다음 라운드가 자동으로 시작됩니다.

### 2. 5:5 영토 실시간 색상화 (빨간색 vs 파란색)
- **내가 차지한 땅: 빨간색 🔴**
- **상대편이 차지한 땅: 파란색 🔵**
- 깃발(경계선)의 이동에 따라 실시간으로 영토 블록이 빨강/파랑으로 물들며, 상단 전광판에 `🔴 나 X : Y 상대 🔵` 형태로 점령 현황이 표시됩니다.

### 3. 각각의 마지막 칸 (낭떠러지 직전) 긴장감 연출
- **1번 칸 (내 쪽 절벽 끝)** 및 **10번 칸 (상대 절벽 끝)**:
  - 위험 경고 빗금 패턴 및 네온 펄스 애니메이션 적용
  - `💀최후선`, `💀적절벽` 라벨 부착으로 벼랑 끝 긴장감을 극대화했습니다.

### 4. 1단계 "파워결정" & 2단계 "가위바위보 결정"
- 1단계: **약파워(1칸)** / **중파워(2칸)** / **강파워(3칸)** (가운데 정렬 아담한 크기)
- 2단계: 직사각형 와이드 형태의 가위 / 바위 / 보 버튼 (클릭 즉시 판가름!)

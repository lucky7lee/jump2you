# 낭떠러지 줄다리기 가위바위보 (5:5 영토 대전)

나의 5칸과 상대 5칸의 정가운데 경계면에서 펼쳐지는 캐주얼 실시간 심리전 가위바위보 게임입니다.

---

## 🕹️ 이번 업데이트 핵심 사항

### 1. 5:5 대칭 영토 & 정가운데 경계면 깃발
- 다리는 **나의 영토 5칸(내1~내5)**과 **상대 영토 5칸(적1~적5)**으로 구성됩니다.
- 애매한 가운데 칸이 사라지고, **5:5 정가운데 경계면(50%) 위에 깃발(🚩)**이 꽂혀 시작합니다.
- 상대를 5칸 이상 밀어내면 상대편 절벽 추락(승리), 5칸 이상 밀려나면 플레이어 절벽 추락(패배)합니다.

### 2. 가위바위보 화면 극대화 (82px 대형 손)
- 게임 중앙의 **나와 상대편 가위바위보 대형 화면이 대폭 확장**되어 박진감 넘치게 손이 순환하고 결과가 클로즈업됩니다.

### 3. 1단계 "파워결정" (크기 축소 & 가운데 맞춤)
- 컨트롤러 명칭이 **"파워결정"**으로 변경되었습니다.
- **약파워** (1칸 - 잽·카운터 최적)
- **중파워** (2칸 - 스트레이트)
- **강파워** (3칸 - 헤비펀치·큰 후딜)
- 가로/세로 크기를 아담하게 줄이고 중앙(Center)으로 정렬했습니다.
- 결과 화면에서도 공간을 차지하지 않도록 **좌측 하단 미니 파워 카드**로 슬림하게 표시됩니다.

### 4. 2단계 "가위바위보 결정" (직사각형 와이드 버튼)
- 큼직하고 안정감 있는 **직사각형 버튼**으로 개편되어 누르기 편하며 클릭 즉시 승부가 판가름 납니다.

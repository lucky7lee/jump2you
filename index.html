📜 낭떠러지 가위바위보 규칙

🎯 게임 목표 (3판 2승제)

가위바위보 심리전으로 상대를 밀어내어 절벽(5칸) 아래로 떨어뜨리면 세트 승리! 먼저 2세트를 따내는 플레이어가 최종 승리합니다.

⚡ 1단계: 파워 선택 및 전진 / 후퇴 규칙

파워 종류 전진력 1판 제한 승/패/무 이동 규칙
🟢 약파워 +1칸 무제한 승리 시 +1칸 전진 / 패배 시 상대 파워만큼 후퇴
🟠 중파워 +2칸 7회 승리 시 +2칸 전진 / 패배 시 상대 파워만큼 후퇴
🔴 강파워 +3칸 5회 승리 시 +3칸 전진 / 패배 시 상대 파워만큼 후퇴
⚡ 필살기 +4칸 3회 상대 3연속 약파워 시 활성화! 승리 시 +4칸 대량 전진

⚖️ 비겼을 때 (무승부 심리 카운터)

• 가위바위보를 비기면 더 낮은 파워를 낸 쪽이 파워 차이만큼 상대를 밀어냅니다!

💡 예: 상대가 [강파워(3)] vs 내가 [약파워(1)]로 비기면 ➔ 내가 2칸 전진! (파워가 같으면 이동 없음)

⏱️ 타임아웃 & 페널티 규칙

• 15초 내 미선택: 약파워(1칸)로 강제 패배 처리됩니다.

• 게임 중도 이탈: 경기 도중 나가면 1패가 추가됩니다.

• 싱글 모드: 새 게임은 항상 1단계부터 시작하며, 3/5/8/10단계 클리어 시 ⭐ 별 및 💎 다이아 마크가 영구 유지됩니다.
